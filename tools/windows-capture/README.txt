Windows capture kit for wine-serato-hw

1. Install the Hercules DJControl Inpulse 500 driver (hercules.com support page) if not installed.
2. Plug in the controller and turn it on.
3. Right-click capture.bat -> Run as administrator.
4. Optional but useful: open Serato DJ Pro once with the controller connected, close it, then run capture.bat again.
5. Reboot into Linux. Results are in the "output" folder.
